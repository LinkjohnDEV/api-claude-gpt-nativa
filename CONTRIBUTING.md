# Como contribuir

Obrigado por querer ajudar! Este projeto é pequeno e aberto.

## Antes de começar
- Procure nas [issues](../../issues) se alguém já falou do mesmo assunto.
- Para mudança grande, abra uma issue primeiro e a gente combina o caminho.

## O que ajuda muito
- **Testar em outras versões do Windows e do Codex Desktop** e contar o resultado.
- Corrigir erro de texto, melhorar a documentação, traduzir.
- Instalador para **Mac e Linux** (está em andamento).

## Regras do código
- O script do Windows precisa passar na **checagem de sintaxe** do PowerShell e **não pode apagar arquivos que não sejam dele**.
- Nunca coloque chave, token ou endereço interno no código ou nos exemplos.
- Cada mudança de comportamento entra no [CHANGELOG](CHANGELOG.md).
- Versões publicadas (*tags*) **não mudam**: correção vira versão nova.

## Como enviar
1. Faça um *fork* e crie uma branch.
2. Faça a mudança e teste (diga na descrição **como** testou e em qual sistema).
3. Abra um *pull request* explicando o problema que resolve.

Seja gentil: veja o [Código de Conduta](CODE_OF_CONDUCT.md).
